# Event Schemas

## Detection Event Schema

Sent from the Analytics layer to the Backend.

```json
{
  "event_id": "c001-20260924T100200Z-GJ01XX0001",
  "camera_id": "C001",
  "timestamp": "2026-09-24T10:02:00Z",
  "event_type": "anpr",
  "vehicle_number": "GJ01XX0001",
  "vehicle_type": "car",
  "confidence": 0.94,
  "bounding_box": {
    "x": 412,
    "y": 260,
    "w": 180,
    "h": 64
  }
}
```

### Validation Rules:
- `event_id`: Must be universally unique. Serves as the idempotency key for deduplication. Format often includes camera ID, timestamp, and entity identifier.
- `camera_id`: Must exist in the database.
- `timestamp`: ISO 8601 UTC string.
- `confidence`: Float between 0.0 and 1.0.
- `vehicle_number`: Will be normalized by the backend (e.g., uppercase, stripped spaces) before watchlist matching.

## Alert WebSocket Message

Pushed from Backend to Frontend via WebSocket when a watchlist match occurs.

```json
{
  "type": "alert.new",
  "timestamp": "2026-09-24T10:02:01Z",
  "payload": {
    "alert_id": 118,
    "severity": "critical",
    "status": "new",
    "matched_identifier": "GJ01XX0001",
    "category": "blacklisted",
    "camera": {
      "id": "C001",
      "name": "Traffic Junction",
      "lat": 23.0225,
      "lng": 72.5714
    },
    "confidence": 0.94,
    "event_id": 5021
  }
}
```

## Camera Health WebSocket Message

Pushed from Backend to Frontend when a camera's state changes.

```json
{
  "type": "camera.health",
  "payload": {
    "camera_id": "C002",
    "old": "online",
    "new": "offline",
    "at": "2026-09-24T10:05:30Z"
  }
}
```

## Concepts

- **event_ids and Idempotency**: `event_id` is generated by the source. If a network retry occurs, the same ID is sent. The backend uses this to ignore duplicates.
- **Deduplication**: Redis checks the `event_id`. Also, alert deduplication ensures that the same vehicle lingering at the same camera doesn't generate 500 alerts in a minute (cooldown).
- **Timestamps**: All timestamps must be UTC ISO 8601 strings to prevent timezone issues.
- **Confidence**: Used to filter out low-quality detections before creating alerts.
- **Normalized plate values**: "GJ 01 XX 0001" and "GJ01XX0001" are treated as the same vehicle for searching and watchlist matching.
- **WebSocket message types**: Differentiate between alerts, health updates, and standard telemetry.
